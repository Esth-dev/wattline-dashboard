# ? Wattline — IoT Energy Supervision Dashboard

A real-time energy supervision dashboard built with **Angular 20**, **TypeScript**, **Angular Signals**, and **RxJS**. Designed with a modular architecture and reusable component system, it monitors real-time power metrics, alerts, and IoT gateway connectivity states.

## ? Key Features
* **Real-time Metrics:** Live KPI tracking for power consumption, voltage, and system alerts.
* **Reactive Architecture:** Modern state management using Angular Signals and RxJS streams.
* **Custom Visualizations:** Native SVG chart components built without heavy third-party chart dependencies.
* **Automated CI/CD:** Continuous Integration and Deployment pipeline configured via GitHub Actions.

## ??? Tech Stack & Architecture
* **Frontend:** Angular 20, TypeScript (Strict Mode), RxJS, Angular Signals, HTML5, CSS3.
* **Design System:** Prototyped in Figma, implementing responsive design and accessibility standards.
* **DevOps & Quality:** Git, GitHub Actions, unit testing, automated deployment to GitHub Pages.
